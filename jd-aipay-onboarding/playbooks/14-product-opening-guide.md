# 产品开通详细引导

## 使用场景

当商户咨询“怎么开通 AI付”“产品开通卡住了”“审核后下一步做什么”“开通后怎么看商户号/appId/agentId”时，读取本 playbook。

## 入口

- 产品开通页：`https://aipay.jdpay.com/process?productId=ai_pay&activeProcessStep=PRODUCT_OPEN`
- 路径：AI付官网 → 快速接入 → 选择产品 → 传统接入方式 → 立即接入/继续接入 → 产品开通。
- 去实名认证模板：`https://qy-web.jdpay.com/select?source=QYZ&channel=00006&scene=SMRZ&bussCode=REAL_NAME&merchantno={merchantno}&r={callback}`（`merchantno`、`callback` 由产品开通页或商户后台上下文带入；参数不明确时，从产品开通页点击「去实名」）。

## 前置条件

- 账号已登录。
- 已确认接入主体类型。
- 已完成或准备完成实名认证。
- 已准备产品开通申请信息；字段以页面实时展示为准。

## 操作步骤

1. 进入产品开通页。
2. 如果页面提示未实名，点击「去实名」并完成实名认证；如需直达实名，可使用模板 `https://qy-web.jdpay.com/select?source=QYZ&channel=00006&scene=SMRZ&bussCode=REAL_NAME&merchantno={merchantno}&r={callback}`，但不要让商户在不清楚 merchantno/callback 时手动拼接。
3. 回到产品开通页填写申请单。
4. 核对所属行业、商户简称、APP 名称、APP 应用市场、结算账户等页面要求的信息。
5. 阅读并勾选产品服务与协议。
6. 点击「申请开通」。
7. 提交后关注审核状态。
8. 审核通过后点击「去签约」，完成合同在线确认与签署。
9. 签约完成后确认产品状态为已开通。

## 审核和签约提示

- 产品开通申请提交后，通常由京东 AI付工作人员在 24 小时内完成审核；实际以页面状态和审核结果为准。
- “审核通过”后还不是全流程结束，必须完成合同在线确认与签署。
- 产品开通成功后，可在产品开通页查看二级商户号。
- appId、agentId 等接入配置通常会发送至预留联系人邮箱，注意查收并妥善保存。

## 不同状态下的主动引导

| 商户当前状态 | 应该回复的下一步 |
| --- | --- |
| 未实名 | 先点击「去实名」完成实名认证；实名通过后回到产品开通页提交申请。 |
| 已实名，未提交申请 | 进入产品开通页填写申请单并提交。 |
| 已提交，审核中 | 等待审核；期间继续技术集成、沙箱联调、证书申请。 |
| 审核通过，未签约 | 立即点击「去签约」，完成合同在线确认与签署。 |
| 已开通 | 查看二级商户号，查收 appId/agentId 邮件，然后进入证书密钥页生成/获取生产密钥。 |
| 被驳回 | 查看页面驳回原因，按要求补充或修改后重新提交；不要猜测驳回原因。 |

## 标准话术

你可以直接进入 AI付产品开通页：
https://aipay.jdpay.com/process?productId=ai_pay&activeProcessStep=PRODUCT_OPEN

如果页面提示未实名，先点击「去实名」完成实名认证；如果已实名，就填写产品开通申请单并提交。实名认证直达模板需要带入 merchantno 和 callback 参数，参数不明确时以产品开通页「去实名」为准。提交后关注审核状态，审核通过后还需要点击「去签约」完成合同确认，签约完成才算产品开通完成。

产品开通过程中不用空等，我可以继续帮你推进技术集成、沙箱联调和证书准备。等产品已开通并完成签约后，我们再生成/获取生产密钥，继续做生产配置替换和线上验证。
