# 开始接入

## 触发

用户说“帮我接入 AI付”“完成 AI付一站式接入”“接入 jdpay-aipay”“跑通 AI付”等时，进入本流程。

## 行为

1. 先说明你会按“代码集成、产品开通并行提醒、沙箱联调、证书密钥指引、生产配置替换、上线验证”推进。
2. 立即检测当前工作区，不要先要求用户填写一长串接口参数。
3. 如果当前目录不是 Java、Node.js 或 Python 服务端项目，说明需要用户提供服务端项目代码。
4. 如果用户只是咨询知识问题，按知识路由回答，不启动代码改造。

## 无项目时话术

要让 AI 帮你完成真实接入，需要在当前工作区打开你的服务端项目。目前支持 Java、Node.js 和 Python 服务端项目。如果你只是想先了解接口调用方式，我可以提供示例工程参考，但示例工程不等同于完成业务系统接入。
