# 平台侧主动下一步路由

## 目的

不要等商户主动问“下一步做什么”。每完成一项任务后，Agent 必须基于当前完成项，主动给出一个明确、可执行的下一步，引导商户继续完成产品开通、实名认证、证书密钥、生产配置替换和线上验证。

## 回复结构

阶段性回复必须包含：

1. **已完成**：说明刚完成的事项和证据。
2. **当前仍需商户处理**：只列最关键的阻塞项，避免一次抛出过多任务。
3. **下一步建议**：给出一个明确动作、入口链接、做完后回来怎么说。

建议句式：

```text
下一步建议：请先完成<动作>。入口：<链接或路径>。做完后你可以回来告诉我“已完成<事项>”，我会继续帮你推进<下一阶段>。
```

## 状态路由

| 刚完成的任务 | 主动引导下一步 |
| --- | --- |
| 项目识别完成 | 确认接入环境；首次接入推荐沙箱，同时提示可并行准备实名和产品开通。 |
| 服务端代码集成完成 | 继续沙箱联调；同时引导进入产品开通页，若未实名先去实名。 |
| 客户端 SDK 集成完成 | 引导服务端联调或沙箱端到端联调；同时提示产品开通可并行。 |
| 沙箱联调完成 | 如果未实名，先做实名认证；如果已实名，申请证书；如果产品已开通，生成/获取密钥。 |
| 实名认证提交完成 | 等待审核；等待期间继续技术集成/沙箱联调。 |
| 实名认证通过 | 申请商户证书，并回到产品开通页提交或查看申请。 |
| 产品开通申请提交 | 等待审核；等待期间做技术集成、沙箱联调和证书申请。 |
| 产品审核通过 | 点击「去签约」完成合同在线签署。 |
| 产品已开通/签约完成 | 查看二级商户号，查收 appId/agentId 邮件，进入证书密钥页生成/获取生产密钥。 |
| 商户证书已准备 | 若产品未开通，继续产品开通；若产品已开通，生成/获取生产密钥。 |
| 证书和密钥已准备 | 进入生产配置替换。 |
| 生产配置替换完成 | 发起小额真实交易并进入线上验证。 |
| 线上验证完成 | 输出最终接入报告，说明已具备正式交易能力及后续运维注意事项。 |

## 常用入口

- 产品开通：`https://aipay.jdpay.com/process?productId=ai_pay&activeProcessStep=PRODUCT_OPEN`
- 去实名认证：`https://qy-web.jdpay.com/select?source=QYZ&channel=00006&scene=SMRZ&bussCode=REAL_NAME&merchantno={merchantno}&r={callback}`（`merchantno`、`callback` 需由页面上下文带入；参数不明确时，从产品开通页点「去实名」）
- 证书密钥：`https://aipay.jdpay.com/process?productId=ai_pay&activeProcessStep=CERT_KEY`
- 线上验证：`https://aipay.jdpay.com/process?productId=ai_pay&activeProcessStep=ONLINE_VERIFY`

## 重要边界

- 不登录商户后台代查状态。
- 不让商户在对话里上传实名材料、完整密钥、证书密码或私钥。
- 不猜测审核结果、风控结论、费率或结算规则。
- 如果缺少状态信息，用“如果你现在是 A，就做 X；如果已经完成 A，就做 Y”的分支话术。
