# 实名认证引导

## 使用场景

当商户出现以下情况时，读取本 playbook：

- 准备提交产品开通申请，但页面提示需要先实名。
- 需要申请商户证书，但账号尚未完成实名认证。
- 咨询企业、个体工商户、自然人/超级个体接入 AI付需要准备什么实名材料。
- 产品开通、证书密钥、上线验证任一步骤被实名状态阻塞。

## 核心规则

- 实名认证是产品开通和证书申请的重要前置动作。
- 不代替商户上传证件，不接收身份证、营业执照、银行卡、授权书等原始材料。
- 只提供材料清单、照片规范、入口路径和下一步建议。
- 实名审核时间以页面和审核结果为准；资料符合要求时，通常需要 1 至 2 个工作日。

## 入口引导

可使用以下两种方式引导商户进入实名：

1. **产品开通页自动跳转（推荐兜底）**：打开 AI付产品开通页 `https://aipay.jdpay.com/process?productId=ai_pay&activeProcessStep=PRODUCT_OPEN`，如果页面提示尚未实名，点击「去实名」，由页面自动带入商户号和回跳地址。
2. **实名认证直达模板**：`https://qy-web.jdpay.com/select?source=QYZ&channel=00006&scene=SMRZ&bussCode=REAL_NAME&merchantno={merchantno}&r={callback}`。其中 `merchantno` 为商户号，`callback` 为认证完成后的回跳地址；如果商户不清楚这两个参数，不要让商户手动拼接，改用产品开通页「去实名」。

进入京东金融企业版/商户后台后，选择与主体一致的实名认证类型并提交材料。

## 材料清单

| 主体类型 | 建议提前准备 |
| --- | --- |
| 企业 | 营业执照、法人身份证、经办人身份证件、授权委托书（授权人不是法定代表人时）、手机号、银行卡 |
| 个体工商户 | 营业执照、经营者身份证、手机号 |
| 自然人/超级个体 | 本人身份证、银行卡、手机号 |

具体必填字段和核验方式以实名认证页面实时展示为准。

## 证照照片规范

提醒商户提交前自查：

- 格式：JPG / PNG / JPEG。
- 大小：单张图片不超过 5M。
- 内容：文字清晰可辨，不遮挡二维码、证件号、有效期等关键信息。
- 拍摄：四角完整、光线均匀、画面清晰。
- 禁止：模糊、反光、遮挡、翻拍、PS、无关水印。
- 如上传复印件，需按页面要求加盖彩色公章，且公章不要遮挡证件内容。

## 授权委托书

企业主体接入时，如果不是法定代表人本人办理：

1. 在实名认证页面下载「委托书模板」。
2. 按模板填写授权人、被授权人和企业信息。
3. 加盖企业公章后拍照上传。
4. 确保证件信息、公章和签署信息清晰完整。

## 标准话术

产品开通和证书申请都需要先确认账号实名状态。你可以从产品开通页点击「去实名」，也可以使用实名认证直达模板：
https://qy-web.jdpay.com/select?source=QYZ&channel=00006&scene=SMRZ&bussCode=REAL_NAME&merchantno={merchantno}&r={callback}

其中 `merchantno` 是商户号，`callback` 是认证完成后的回跳地址。如果你不清楚这两个参数，请不要手动拼接，直接从产品开通页点击「去实名」：
https://aipay.jdpay.com/process?productId=ai_pay&activeProcessStep=PRODUCT_OPEN

请注意，我不需要你把身份证、营业执照、银行卡或授权书发给我；你只需要按页面上传。提交前重点检查图片清晰度、四角完整、无反光遮挡，企业经办人非法定代表人时记得上传盖章授权委托书。

## 完成后的主动下一步

- **实名已提交，等待审核**：引导继续完成技术集成和沙箱联调；如果已经完成技术联调，提示等待实名结果。
- **实名已通过，证书未申请**：引导进入证书密钥页申请证书，入口 `https://aipay.jdpay.com/process?productId=ai_pay&activeProcessStep=CERT_KEY`。
- **实名已通过，产品未申请**：引导进入产品开通页提交申请，入口 `https://aipay.jdpay.com/process?productId=ai_pay&activeProcessStep=PRODUCT_OPEN`。
- **实名驳回**：让商户按页面驳回原因修正材料；不要猜测审核结论。
