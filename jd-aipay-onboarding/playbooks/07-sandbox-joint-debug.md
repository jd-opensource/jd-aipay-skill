# 沙箱联调

## 目标

确认商户服务端代码能够在沙箱环境完成 AI付接口调用，并定位接口、签名、加密、配置类问题。

## 沙箱环境配置

| 项 | 值 |
| --- | --- |
| 网关域名 | `https://fpitest.jd.com` |
| 接口路径 | `{域名}/api/pay-ai-agent/<接口名>/{沙箱实例ID}` |
| 沙箱实例 ID | 商户在平台创建沙箱后获得（如 `2099854417468633089`），**由用户自行填写**，追加在接口路径后 |
| 京东 SM2 公钥 | 与 pre/prod 共用内置共享证书（`assets/certs/jd-sm2-pub.b64`），沙箱无单独公钥时无需额外配置 |

使用 `scripts/render_server_example.sh` 渲染时：`env=sandbox` + `sandbox_id=<你的沙箱实例ID>`，`base_url` 可省略。

## 行为

1. 使用项目内的沙箱配置或用户提供的沙箱参数；沙箱实例 ID 未提供时，引导用户到平台创建/查看沙箱并获取。
2. 优先跑通下单和支付结果查询；退款链路按商户需求继续验证。
3. 输出调用接口、环境、请求结果、响应摘要和是否通过。
4. 失败时先区分配置缺失、证书密钥、签名、bizContent 加密、HTTP header、网络和业务状态问题。
5. 查询 `reference/api/` 获取字段、状态码和签名加密规则。

## 注意

产品开通不必完成后才做沙箱联调。产品开通审核期间，技术集成和沙箱联调可以继续推进。
